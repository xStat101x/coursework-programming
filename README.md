## History and rollback

Original repositories, deployments and pull requests remain unchanged. You can return to those originals at any time. See [MIGRATION.md](MIGRATION.md) for preservation details and limits.

Original whole-project branch snapshots are retained under source/<repository>/<branch>. They use original root paths; use main for the category folder layout. Projects history was mapped into the destination paths; original signed history remains in xStat101x/Projects and verified local backups.

## Running projects

Each folder is independent. Use that folder’s README, dependencies and tooling. No dependencies, lockfiles, licenses, notebooks or source files were changed during import. Automation is disabled for staging; no deployment or package publishing was performed.
